What changes between methods

All methods use the same NAB files, the same chronological 60/20/20 split, the same LSTM Autoencoder and the same reconstruction errors e(t). Only the rule that converts e(t) into an alarm changes.

B1 threshold = p-th percentile of training errors. B2 = mean + k·σ of training errors. B3 = mean + 3σ of the previous w errors (2026 base paper).

P1 (proposed) threshold(t) = median(et−w…t−1) + λ · MAD(et−w…t−1). Its memory can be plain (every error enters the window) or gated (an error that triggered an alarm is not added to the window, so an anomaly cannot raise the bar it is judged by; alarms lasting longer than w steps are accepted as a new normal). λ, w and the memory type are chosen on validation data only.

How the metrics work

Point F1: every time step in a NAB window is a positive. Event recall: share of windows with at least one alarm. Composite F1 = harmonic mean of point precision and event recall (Garg et al., 2021) — counts each event once but still punishes every false alarm.

NAB score: official Numenta scoring (verified against sweeper.py): early detection inside a window earns up to +1, a missed window costs −1, each false alert costs up to −0.11. Normalised so 0 = never alarming and 100 = perfect. Alarms are counted as alerts at their onset.

High-variance FPR: false-positive rate on normal test points whose rolling std is above the 75th percentile seen in training — the "changing normal variability" of RQ3/H2.

ROC-AUC / PR-AUC measure the LSTM-AE score itself and are identical for all threshold rules (RQ1).
